# TaskFlow - To-Do List App

## Project Overview
TaskFlow is a simple, responsive To-Do List web application developed as part of the Front-End Development Internship at Auspify Technologies.

## Features
- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all completed tasks
- Automatically save tasks using browser localStorage
- Responsive design for desktop and mobile devices

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Project Files
- `index.html` - Website structure
- `style.css` - Website styling and responsive layout
- `script.js` - Task functionality and localStorage

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Add, complete, or delete tasks.
